# 求职兼职演练闭环验收

验收日期：2026-11-11 至 2026-11-12。项目本地开发服务，测试使用独立 localhost 来源；未清空用户在 127.0.0.1 来源下的记录，未部署公网服务。

## 本轮变更

- 对话请求携带受限的最近会话、引用内容和已操作的核实渠道。支持一轮同时询问工作、报酬、时间，以及基于上文追问。当前输入不会重复加入历史。
- 模型只选择允许的答复主题，事实仍由情境材料控制；输出无效、超时或无可用额度时使用同一套多问题规则回复。拒绝和提示注入不触发模型请求。删除具体回答后重复追加“材料未明确”的兜底句。
- 增加决定理由输入；复盘把用户自述与实际操作证据分开，按真实动作显示核实缺口、材料冲突、时间线、情境诱因和对应练习。不把重复查询当作更多核实渠道，不把情境诱因当作心理诊断。
- 修复学习中心首次加载未恢复网址参数的问题。复盘中的课程、专项题组能直接打开正确内容，刷新后仍保持对应范围。

## 浏览器验收

1. 引导演练：打开培训费附件，查询 QH-061，使用工作室公开联系方式，选择暂缓办理并填写理由。复盘显示 2/2 独立渠道、已查看附件，准确呈现联系人授权与收费要求冲突。
2. 专项学习：从复盘进入 job-fee 题组，实际显示该题组的 2 道题；提交第一题后显示判断、解释与资料依据。返回复盘后进入 job-fee 图文课程，标题与内容均匹配。
3. 独立挑战：通过复盘入口进入“面试通过之后”，联系人、工作室、岗位、附件与风险均不同。YF-204 在预置目录中存在，但私发软件、屏幕共享不符合公开邮箱办理要求，联系人也未获授权。
4. 挑战结束：填写依据并结束沟通。复盘正确区分岗位存在与联系人授权，推荐 job-app 课程和题组。返回情境选择成功；再打开复盘可恢复已结束记录。
5. 模型冒烟：在已有本地测试登录下实际成功调用 1 次。用量页返回 succeeded=1、failures=0、tokens=1038；验证接入通路，不代表所有语言输入均已覆盖。该次发现的重复兜底已增加回归测试并修复，未为此重复消耗实际模型调用。
6. 视觉：在当前桌面视口检查完整复盘与会话，纯白内容、分层标题、独立行动时间线，无页面横向溢出。临时移动视口设置未改变工具返回的实际宽度，因此本轮不声明已完成新复盘的手机实测；临时设置已重置。

## 保留边界

当前求职场景使用模型进行上下文主题选择和受控答复组合，并非开放式无限角色生成。该场景复盘按操作规则整理，不应对外宣称为模型心理测评。核实工具为虚构教学材料，不能提供现实身份认证或司法证据。记录仍保存在当前浏览器且只保留最近一轮求职演练；新开一轮会替换上一轮。本轮未包含语音或实时人像验收。
