# 情境演练操作与结果反馈

本次更新将“核实信息”和“作出决定”放在聊天顶部。核实结果保存在本轮操作记录中，可关闭抽屉后重新查看；提交决定时可明确选择发现的问题，并保留判断理由。

本轮结果根据操作日志、提交的发现与最终决定计算：安全停止、有依据识别并阻断、停止风险操作、继续办理风险未排除。直接结束沟通不会自动记为识破骗局。

五项行动成就分别记录独立求证、分清身份、发现矛盾、守住边界、及时纠偏。身份与流程判断必须有对应的独立材料，不能仅靠勾选获得。安装只记录模拟点击；后续停止不会清除已发生的风险记录。无需以收集全部成就为目标。

当前判断采用可核查的规则与用户提交的结构化发现，不宣称自动理解、评分所有自由表达。旧记录缺少发现字段时保持兼容，不追补身份或流程识别成就。
