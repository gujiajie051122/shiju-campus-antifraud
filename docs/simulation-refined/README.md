# 情境演练界面统一优化（2026-11-17）

## 本次改动

- 岗位资料采用职位、来源、编号、工作内容、工时和报酬字段排版，不重复套纸张卡片。
- 两个模式的附件使用正式章节、中文字体、落款与页脚；网页阅读版支持文字选择和75%至150%缩放，可下载真实的单页PDF。

### 验收中发现并修复

1. 手机文件被整页缩小，正文过小，落款超出纸张：改为最小14px正文、响应式重排及随内容增长的白纸高度；复查正文与页尾通过。
2. “查看安装请求”点击即记录安装，标签含义不准确：改为“模拟安装协作助手”，点击前明确说明仅记录选择，不下载或开启屏幕共享。
3. 弹窗与背景同时滚动，禁用按钮影响焦点循环：增加背景滚动锁定，只在可用控件间循环焦点；选择行动不再重置焦点。
4. 引导演练结果机械显示“未点击模拟安装”：改为按实际记录显示风险操作，继续办理不会显示为无风险操作。
5. 待核实材料与上方建议条件可能不一致：侧栏按实际缺少的材料显示，避免空列表。
