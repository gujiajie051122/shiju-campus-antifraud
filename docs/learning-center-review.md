# 学习中心实施与验收（2026-11-09）

## 范围

- 首页保留真实案例轮播。统一五个入口：`/`、`/learn`、`/simulation`、`/review`、`/records`。
- 学习中心分为课程学习、题库练习、知识问答；其余模块复用现有演练、复盘与记录功能。
- 四节入门课：招聘核实、刷单返利、沉没成本、AI伪造与身份核实。正文附来源与适用范围。三课链接现有案例原站报道，**不是已制作四套视频课程**。
- 十道固定选择题，作答后给解释与依据；按课程筛选、错题重练、查看本轮小结。题库不是AI即时生成。记录最近一次作答，不提供能力认证。
- 阅读标记、最近作答保存在当前浏览器；跨设备不共享。问答只在当前学习页面保留，刷新或离开后清空，不计入长期记录。

## 知识问答

- 扩充到11条有出处的知识要点。新增沉没成本、AI图像/视频伪造、声音克隆、社会工程学。
- 保留最近20轮显示，最多传最近3轮上下文用于理解追问；模型的事实依据仍限于本次检索的已收录内容。
- 支持通俗解释、例子与步骤追问、手动停止、新话题。按真实状态区分模型讲解、已收录知识要点和资料不足。
- 来源来自公安机关提示、论文摘要、FBI/IC3及FTC；原创教学例子明确标注，不冒充论文案例或个人心理诊断。
- 不承诺能回答所有理论问题。检索无匹配时不调用模型；模型异常或额度限制时回退到收录要点。引用校验能拦截无效来源ID与部分不支持的输出，不能保证语言模型每个语义判断绝对正确。
- 保留已有服务端密钥与请求预算机制；没有新增外部服务或修改账号权限。

## 验收结果

- `npm run typecheck` 通过；`npm test` 80/80；`npm run build` 通过。构建仍有现有大包提示，不能据此声称性能已全面优化。
- 自动检查新增课程/题目引用完整性、作答与进度数据约束、历史消息角色及长度限制、多轮追问、主题切换、无匹配问题及历史不作为事实依据。
- 浏览器实测：标记已读→本课练习→错误回答→错题重练→订正→本轮小结；跳转学习记录后仍显示已读1课、已答1题、错题0道；刷新/返回学习页仍保留。
- 实际模型调用：解释沉没成本→“再简单讲一下”保留话题并换通俗说法；AI伪造课程问题带入输入框后可提交并得到讲解，展开依据可见真实来源与适用范围。
- 无关问题“为什么今天会下雨？”显示资料不足，未硬套上一轮反诈讲解。纯检索路径下的连续追问和主题切换另有自动检查。
- 五个入口均可单独打开；1440×1000桌面、390×844手机检查。手机学习页文档宽度等于视口可用宽度，无横向溢出。
- 开发中首次新建CSS出现一次缓存的缺失模块报错，通过重新触发布局编译解除；之后页面和交互可用。

## 仍需后续内容工作

当前是可运行的学习闭环，课程和题库规模有限。正式参赛前需要持续审核扩充资料、题目与边界问题，制作或获取授权的教学视频，并进行更多真实用户学习效果评估。不能把本次功能验收当作教学效果研究或获奖保证。
