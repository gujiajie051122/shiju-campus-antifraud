# 学习中心素材与内容说明

核对日期：2026-11-10。实际目录由 `lib/video-courses.ts`、`lib/course-content.ts` 和 `lib/course-notes.ts` 提供。

## 课程范围

六类问题各有五节原创图文微课，共30节，分别讲解独立的判断问题、情境和核实步骤。另收录五条真人讲解、五条动画教学，作为外部学习资料。视频按当前已核实的内容归类，并非每个专题各有五条视频。

图文情境为教学编写，不冒充真实案件；报道图片仅作专题配图，不表示画面中的人是本课讲师。视频封面来自对应视频原画面，不使用生成的人像冒充授课者。
