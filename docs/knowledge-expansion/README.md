## 回答行为

模型已有配置保存在本地 `.dev.vars`，本次未更换供应商或密钥。源码归档继续排除真实环境文件与密钥。模型参数仅在服务端读取。

- 概念问题先解释，具体遭遇优先给出风险与行动；关键信息不足时追问，不索要敏感凭证。
- 简短行动追问联合前文检索，并优先保留转账后报警、共享屏幕、验证码或追损的应对资料。
- 仍使用最多3条检索资料；模型输出1—4段带来源ID的文字。
- 继续检查来源ID、数字及不当认证表述；这是有限的程序校验，不能保证所有语义绝对正确。
- 不支持实时联网查证账号、链接或人员；无相关资料时说明边界。用户历史不提升为来源证据。
- 未登录、额度不足或模型失败时继续显示资料要点，保留现有登录与费用控制。
