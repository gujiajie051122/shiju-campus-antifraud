# 识局校园聊天界面验收

日期：2026-11-11。范围：求职情境聊天页及用户自己的大学生头像。结论：通过本轮视觉与交互验收；不代表整站功能已经全部验收。

## 视觉依据

- 用户已批准的效果图：`reference.png`，1584 × 992。
- 电脑实际页面：`desktop.jpg`，CSS 视口 1584 × 992；手机实际页面：`mobile.jpg`，CSS 视口 390 × 844。
- 在同一次图像输入中同时查看效果图与实际页面，并单独查看手机图。截图保留完整网页上下文，没有用效果图代替实现截图。
- 浏览器截图接口存在 Windows 缩放比例导致的裁切问题，最终以显式裁切范围补偿截图接口比例，核对实际图片覆盖完整 CSS 视口；未改变网页样式来美化截图。

## 五项保真检查

| 表面 | 结果与有意差异 |
| --- | --- |
| 构图与间距 | 保留左侧联系人、中央聊天、底部输入区、上部功能导航。手机隐藏联系人栏，聊天与输入区占满可用宽度。 |
| 字体与层级 | 消息正文 17px，手机 14px；消息、姓名、文件标题、辅助信息各有层级。比效果图更紧凑，保证实际长消息与手机阅读。 |
| 颜色与材质 | 白色接收气泡、绿色发送气泡、浅灰联系人栏、真实校园照片背景；照片加轻遮罩保证文字可读。 |
| 素材与细节 | 单独生成并优化校园壁纸与虚构招聘联系人头像。根据用户追加要求，将山景自用头像改成白衣、深色背包的大学生形象。保留现有识局 Logo。 |
| 状态与内容 | 截图为独立挑战“面试通过之后”，因此角色名、附件和对话与效果图中的引导演练不同。保留真实场景状态，未伪造固定聊天记录、文件体积或可点击的第二联系人。 |

## 实测

- 消息发送后出现自己的绿色气泡及大学生头像，对方回复出现白色气泡。
- 引用消息能进入输入区，发送后保留引用内容；新增记录恢复和畸形引用校验测试。
- 岗位卡片、PDF 示意材料可打开和关闭；核实工具可展开与返回。
- 联系人搜索无匹配时出现空状态，清空后恢复联系人。
- 手机 390 × 844 下页面 scrollWidth 为 390，输入区底部约 843px，没有横向溢出；完整截图可见发送按钮。
- 类型检查通过；90 项测试通过；生产构建通过。构建仍有既有大分包提示，不将它写成无警告构建。

## 修复与边界

- 将长篇第三人称岗位材料式回复改为自然角色口吻。
- 用独立的岗位卡片与 PDF 消息呈现材料，避免把业务说明面板塞进聊天区。
- 搜索、引用、表情、材料与核实入口保留实际行为。
- 本轮对话测试使用了情境预设回复，不能据此宣称开放式模型回答质量已全部验证。
- 附件是教学示意材料；核实渠道是情境内模拟。人物、头像与机构名称为演练设定。

最终比较未发现阻塞本轮交付的 P0/P1/P2 视觉问题。实际实现与效果图之间的差异已在上表明确列出。
