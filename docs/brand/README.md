# 识局 Logo 素材

- approved-reference.png：用户选定的“破局”方向参考图。
- logo-source.png：基于参考图生成的透明底图标与“识局”横向组合。
- mark-source.png：同方向独立标志。
- public/brand/shiju-logo.webp：仅裁去透明边距并压缩尺寸，实际网页使用素材。
- 深色版通过 CSS 单色反白呈现；浅色版保持绿色及橙色出口。
- 浏览器图标由独立标志等比缩小，透明底，未手绘替代。

素材生成要求：保留选定开放迷宫图形和“识局”字标，绿色配橙色出口，透明背景，无额外标题、说明或展示底板。独立标志保持相同轮廓，仅移除字标。反白生成变体存在背景杂点，未用于项目。

QA 截图与说明见 qa/ 和项目根目录 design-qa.md。
