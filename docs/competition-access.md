# 比赛评审访问方式

更新：2026-11-17。比赛版本默认免登录，评委不需要创建账号、登录ChatGPT或填写模型密钥。

## 已实现

- 知识问答、情境文字对话、AI复盘共用匿名访客体验额度；课程、题库和本地学习记录继续直接使用。
- 首次访问由服务端分配随机访客标识，保存在同站HttpOnly Cookie中，不收集姓名、手机号或IP作为身份。此标识只用于额度分组，不代表认证账号。
- 当前默认每位访客每日40次、全站每日200次模型调用；站点并发3、访客并发1、每分钟6次、调用间隔1.5秒。上海时间零点重置。评审规模增大时由站点维护者调整环境配置。
- 清除Cookie可能重置访客分组，所以全站原子额度限制始终是实际费用上限；不把访客额度当作防滥用的绝对保障。
- 配额耗尽、网络异常或模型失败时保留预设演练和资料回答，不将用户导向登录才能继续的死路。
- 可选环境变量AI_REQUIRE_SIGN_IN默认为false，仅在以后明确需要账号访问时设为true。比赛部署应保持false或不设置。

## 实际验证

全新未登录会话调用本机网页接口：知识问答engine=model、无budgetCode，额度40→39；另一全新会话依次调用情境对话与AI复盘均为engine=model、无登录提示，额度40→38。记录见knowledge-expansion/guest-feature-live.json。复盘仍需用户确认发送操作摘要，这是内容发送确认，不是账号登录。

138项自动测试、TypeScript检查、目标文件ESLint与生产构建通过。测试包含匿名访客持续计费、三项功能共享额度、无效Cookie处理、访客切换不能绕过全站上限。课程/题库已有的功能验证沿用此前记录，本次没有重新逐题检查。

## 提交前仍需完成的部署步骤

1. 提供评委能从其他电脑、手机访问的稳定公网HTTPS地址。127.0.0.1是本机地址，不能作为远程评审地址。
2. 在正式服务器配置LLM_BASE_URL、LLM_API_KEY、LLM_MODEL及LLM_OUTPUT_FORMAT；密钥由站点维护者配置，评委不需要接触。源码包不包含真实密钥。本机Cloudflare运行配置保留在.dev.vars。
3. 正式环境绑定DB并执行drizzle/0000_lucky_hammerhead.sql中的数据库初始化，确认ai_requests表可用；模型费用控制依赖数据库，缺少数据库时保留预设回复而不直接发起无上限调用。
4. 根据评委人数与评审时间安排站点额度、模型服务余额和有效期。
5. 用未登录/无痕浏览器从公网地址验证问答、情境演练、AI复盘、课程、题库、记录和移动端。当前仅完成本机真实接口验证，未宣称公网部署已经完成。
