# 求职演练收尾验收 · 2026-11-12

本轮范围：现有求职兼职案例的多轮保存、按轮回看与手机布局验收；未新增其他诈骗情境。

## 完成行为

- 新建一轮前，将已有最近一轮合并到历史记录。按轮次 ID 更新，继续旧练习不会删除更新的其他轮次。
- 学习记录同时展示未结束和已完成的轮次；前者打开对应聊天，后者打开对应复盘及完整对话。
- 每轮提供单独 JSON 导出。早期版本的练习继续保留，相关导出和删除按钮明确标记为“早期练习”。
- 损坏的历史记录不会被静默清空；历史存储写入失败时，不替换先前的当前轮次，并显示保存失败提示。
- 复盘中的聊天回看只展示原消息，不将用户的自述补算为已经完成的核实行为。

## 浏览器实际验收

在 localhost 的本地验收会话中操作，未清空或改写 127.0.0.1 上的用户练习记录。

1. 原独立挑战“面试通过之后”已结束，包含目录和联系人两类核实操作，可打开对应复盘。
2. 新建引导演练“群里转来一份兼职”，查看入职附件，发送“ 不交培训费，我先暂停。 ”，得到暂停沟通的对应回复。
3. 学习记录同时显示上述两轮。新一轮建立后，再次打开原独立挑战，复盘仍对应原轮次及原核实结果。
4. 从记录恢复未结束练习，再刷新页面，原 3 条对话消息及附件“已查看”状态仍在。
5. 390 × 844 浏览器视口检查聊天、附件弹层、历史复盘与记录列表。聊天文档宽度为 390px，无水平溢出；输入区在视口底部可达。复盘对话可展开阅读。
6. 临时手机视口已重置。正常窗口实测宽度 887px、文档宽度 872px，无水平溢出，列表与侧栏可正常显示。

## 范围与限制

记录保存在当前浏览器，没有云端账号同步；清理浏览器数据或切换设备不会自动带回记录。旧版本在本轮改动前已经被覆盖的轮次无法恢复。本轮验证的是浏览器响应式布局，尚未覆盖实体手机软键盘及不同移动浏览器。本轮未新增付费模型调用。

本记录取代上一轮验收文件中“仅保存最近一轮”和“复盘手机视口未实测”的限制；其他模型、安全和素材范围说明继续适用。
