# 图文微课改版 · 2026-11-10

范围为课程目录与图文阅读页。首页、真人及动画视频来源未在本轮修改。

- 六个专题各五节，共30节；图文筛选每页六节，首屏覆盖六个专题。
- 每节使用独立的1200×800 WebP教学配图，图片由内置图像生成工具制作。它们是虚构教学示意，不是真实案件照片，不作为案件或学习效果证据。
- 教学正文使用可选择的网页文字；图内的小字仅为场景细节，不承担必须阅读的知识。正文提供情境说明、观察点、三步核实方法、提醒和题目解析。
- 学习流程为“看案例—学核实—做判断”。提交判断后才可完成课程；完成代表阅读练习记录，不代表现实中不会受骗。
- 原有课程ID、题目ID、来源与本地学习记录结构保持兼容。记录仍仅保存在当前浏览器，不是账号云端同步。
- 真人与动画视频沿用原始封面及原站链接；公开可访问不等于已获得再分发许可，原有发布边界见 `../course-media-review.md`。

## 素材与验收

`assets.json`列出30张图的路径、尺寸、字节数和SHA-256。素材总大小约4MB，单图均小于200KB；列表懒加载，阅读主图优先加载。

`qa/`保留浏览器实拍、30图联系表、参考/实现同图比较和尺寸元数据。`compare.mjs`可在本机重新生成对照图，左侧参考、右侧实际，不拉伸图片。

浏览器检查包括目录筛选/搜索/分页、空结果、三阶段导航、图像放大与Escape关闭、错答重试、正确反馈、完成及刷新恢复、专题切换、课程问答预填与关联题库、手机和平板布局。测试会在本地浏览器增加少量学习记录，没有清空原记录。

最终 `npm test` 84/84通过，`npm run typecheck` 和生产构建通过。目标文件ESLint无错误、5条原生img建议警告；图文图片已预压缩为WebP。构建保留现有大chunk和vinext路由静态分类提示，未声称性能全面达标。未发布公网，也没有在本轮调用付费模型/数字人服务。
