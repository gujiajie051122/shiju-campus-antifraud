# 情境对话机制修正（2026-11-17）

本次修改当前不

- 模型由选择replyIds改成在虚构招聘事实约束内生成联系人正文，结合最近8条消息、引用、附件是否查看和已取得的核实材料。
- 阶段区分初步沟通、办理要求、受到质疑、停止；意图区分提问、犹豫、愿意继续、质疑、明确退出。由服务端从本轮上下文计算，不将模型返回的状态作为核实证据。
- 联系人围绕群转发、面试通过与办理前提扮演带诈骗风险的角色；教学说明继续由学习提示、核实工具与复盘承担。已独立查明矛盾后不篡改查询结果，不编造授权补录或假目录。
- 保留事实与操作约束：不能编造薪资/计薪方式、预算原因、名额、退款承诺和按钮；不提供真实付款、软件下载、账号或验证码收集路径。用户明确退出后停止推进。
- 连接异常或回复不符合校验时显示预设回复及提示，预设也修正为联系人口吻；没有声称所有预设回复都是AI生成。
- Qwen关闭思考模式以降低本场景延迟。其他模型保持原配置。

真实接口连续复测见role-live-after.json：六种分支中四次模型生成、一次校验回退、一次明确退出直接规则回复。模型生成耗时约1.2至2.2秒；这是本机小样本，不是性能保证。相比修改前18秒超时和愿意继续却收到退出答复，本轮愿意继续已指向真实的会话菜单；工资追问结合前文作答；独立查到矛盾后联系人不再讲解防骗方法。

仍有边界：生成回复可能因事实校验回退，当前只有两条招聘情境，不代表已覆盖全部诈骗类型。本次没有进行公网评委访问验收。自由文本事实校验无法形式化保证每句语义，后续仍需持续抽查。

验证：139项自动测试、TypeScript、目标文件ESLint、生产构建；桌面原v0.3.1主线压缩包原位更新。
