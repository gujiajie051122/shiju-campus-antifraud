# 识局 · 校园反诈演练（单场景验证版 v0.2）

当前交付是“兼职招聘”可运行版本，包含风险和正常招聘对照，用于验证交互与记录规则。尚不是完整参赛作品，也不构成防骗能力认证。

## 本机启动
需要 Node.js 22.13 以上。依赖已安装，可直接双击“启动识局.cmd”，或运行：

```powershell
npm run dev -- --host 127.0.0.1 --port 5173
```

浏览器打开 http://127.0.0.1:5173 。保持启动窗口打开。第一次从源码安装需联网运行 npm install。

## 体验路径
1. 选择模式后开始练习，随机进入风险或正常情境，开始时不揭示分组。
2. 查看岗位和编号，自由提问；可记下联系人身份、报酬与结算等待确认项。
3. 主动查看“入职要求说明”。在独立核实中输入岗位编号 QH-061 或联系人称呼“林老师”，或选择回拨号码的来源。输错查询和对方提供的号码不计为独立核实。
4. 选择暂停、继续、退出或模拟报告，确认后复盘。
5. 先对照联系人说法与已取得的独立结果；未取得的材料保留待确认状态。完整记录默认收起，可从评价依据跳转展开，再填写自己的解释。
6. 重演要求前节点：原分支保留，节点后的信息清除，之前取得的信息保留。
7. 切换对照练习后旧练习进入往期记录。最近20组保存在当前浏览器；长期保存请导出JSON，包含所属的重演前分支。
8. 复盘下方展开“查一条建议”，查询兼职费用、身份与回拨渠道等问题；每一点可展开资料摘要、段落定位、日期和原文链接。资料不足时不生成答案。

## 可选账号配置
无需账号即可运行文字版。复制 .env.example 为 .env.local，仅在本机填写，重启服务生效。

- LLM_BASE_URL：HTTPS兼容Chat Completions的API基址，程序追加 /chat/completions。
- LLM_API_KEY / LLM_MODEL：服务端模型密钥与模型名。模型收到最近8条交流和程序提供的可见事实，不接收未打开的费用卡或正常/风险组标签。模型文本不会触发核实、决定或改变状态；服务失败、结构不合格、虚构数字等情况回退预设回复。
- LLM_OUTPUT_FORMAT：默认schema，需要服务和模型支持严格JSON Schema；仅支持JSON模式的兼容服务可选json，两种模式均做本地字段和引用校验。未指定服务商或默认付费模型。
- DID_AGENT_ID / DID_CLIENT_KEY：数字人Agent ID及浏览器用公开client key。必须在服务商后台限制来源域名，不可填账号API secret。只使用自有或获授权的虚构角色。

模型密钥不会返回浏览器；公开client key按SDK设计由浏览器使用。不要提交 .env.local 或在聊天中发送密钥。托管站点需单独配置运行时环境，本机配置不会修改线上环境。

## 检查命令
```powershell
npm run typecheck
npm test
node tests/http-check.mjs
npm run build
```
HTTP检查需开发服务器在5173运行，可通过 CHECK_URL 指定地址；无论是否配置模型，该脚本均不发起供应商请求。41个自动检查覆盖场景、模型约束、服务异常、检索和输入边界，其中一项遍历256种决策与核实组合。自动检查中的模型响应为受控测试数据；真实联调另行记录，不等同于大样本质量或训练效果验证。

引用编号校验能排除不存在的来源，不能证明模型每句话都被原文支持；事实与引用的语义一致性仍需教师审校和真实模型评估。检索资料是人工整理摘要，不是实时互联网搜索，也不对现实案件作违法认定。

## 核心代码
- app/page.tsx：演练、复盘、记录、设备设置。
- lib/scenario.ts：确定性情境、事件、核实、检查点与复盘。
- lib/avatar.ts：数字人适配，只用speak播报场景控制后的回复，不使用服务商聊天代理。
- app/api/dialogue：受控对话与模型降级。
- lib/dialogue.ts、lib/model-service.ts：可见事实、对话上下文、结构化输出与回退。
- lib/knowledge.ts、lib/knowledge-answer.ts：可追溯语料、BM25检索、模型整理与引用校验。
- app/components/KnowledgeDesk.tsx、app/api/knowledge：复盘内资料查询。
- app/api/status、app/api/avatar：服务状态和公开SDK配置。
