# 识局 校园反诈学习与情境演练平台

2026年第九届传智杯省赛作品。提交版本为 v0.3.1，2026年11月18日封版。

识局帮助学生从情境材料中找到值得核实的问题，通过图文课程、题库、知识问答、文字情境演练及基于操作依据的复盘，练习独立核实与决策。

## 功能与使用方式

1. 首页浏览校园反诈案例、来源与学习入口。
2. 学习中心包含30节本站图文课程、960道练习题和知识问答。960题按120个教学情境组织，并非960个独立真实案件。材料分析题提供文字作答与参考要点，不自动评定表达对错。
3. 情境模拟提供引导演练与独立挑战。角色为虚构联系人，目录和授权材料为预置教学材料，不查询真实机构。
4. 用户查看材料、独立核实、保存判断理由并作出决定；复盘区区分安全停止、有依据阻断、风险操作及纠偏。AI复盘须经用户确认后生成。
5. 学习记录汇总课程、题库和演练，支持筛选、分页及JSON导出。记录保存在当前浏览器，不跨设备同步。

## 技术架构

TypeScript、React 19及App Router结构；Vinext和Vite负责开发与构建；Cloudflare Workers承载服务端接口，D1/SQLite记录模型调用额度和用量；Drizzle维护数据库结构。界面使用现有CSS与lucide-react图标。

AI通过服务端兼容Chat Completions的接口接入，不在前端保存密钥。知识问答先检索本地整理资料，再生成带来源ID的回答并校验；情境对话使用角色、阶段和已见材料；复盘按操作摘要和已保存理由整理重点。检索采用本地规则、标签和排序，未使用向量数据库，不声称具有自主多智能体能力。

## 安装和本机运行

建议 Node.js 24 LTS（package.json最低22.13），使用npm和锁文件；首次安装需联网下载依赖。

```powershell
npm ci
npm run dev -- --host 127.0.0.1
```

浏览器打开 http://127.0.0.1:5173 。保持服务进程运行。Windows安装依赖后也可双击“启动识局.cmd”。浏览器数据与本机数据库独立保存，压缩包不带开发者原有记录。

## 模型和数据库配置

不配置模型时仍可使用课程、题库、预设文字演练和资料检索；这些回复会按实际方式标注，不应当作真实模型生成。

如需三项AI功能，复制模板为Wrangler本地配置文件，并填入自己的服务端配置：

```powershell
Copy-Item .env.example .dev.vars
```

设置 LLM_BASE_URL（HTTPS服务根地址，通常含/v1）、LLM_API_KEY、LLM_MODEL；LLM_OUTPUT_FORMAT选择schema或json。密钥不得提交到仓库或网盘。比赛默认 AI_REQUIRE_SIGN_IN=false。

开发服务首次启动后，在同一项目目录的另一个终端初始化本地额度数据库：

```powershell
npm run db:init:local
```

该迁移用于新数据库；不要在已有业务数据库上重复执行或删除数据。若使用不同本地持久化目录，应给开发服务与命令使用相同目录。配置正确与否可通过 /api/status 和 /api/usage 检查：缺少DB时会限制模型调用并保留兜底回复。

默认每位匿名访客每日200次、全站每日1000次、站点并发3、每分钟6次、最短间隔1.5秒，可通过.env.example中的变量调整。每日额度按上海时区重置。全站额度用于限制调用次数，不等同于固定金额预算。

## 检查与构建

```powershell
npm run typecheck
npm test
node tests/http-check.mjs
npm run build
```

HTTP检查要求先启动开发服务，默认不调用成功的付费模型生成。151项自动测试、类型检查、构建及最近一次本机HTTP检查已通过；证据见docs/records-overview/。AI真实接口检查证据见docs/knowledge-expansion/，不代表穷尽所有用户表达或人工审校全部960题。

npm run start 基于已构建的dist/server/wrangler.json运行本机生产预览；它不是公网部署。正式部署需自行创建并绑定D1，执行迁移、设置模型秘密与配额，保持评审期间可用。仓库配置含本地占位数据库ID，不能原样视为线上服务已配置。
